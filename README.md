# FATA News | فاٹا خبریں 🏔

News of the former FATA — now the merged tribal districts of Khyber Pakhtunkhwa — in one list. Urdu and English, portrait only.

- **Swipe down on the list to refresh** (pull-to-refresh), plus an automatic refresh every 5 minutes.
- Sections: FATA overall, Bajaur, Mohmand, Khyber, Orakzai, Kurram, North Waziristan, South Waziristan.
- News language filter: all / Urdu / English. App language: Urdu / English (button at the top).
- Each story shows the news outlet, how old it is, the district and a 🔴 tag for stories under 3 hours old.
- Tap a story: it opens in the app's own browser. Long-press: share. Search box. The last stories are saved for offline reading.
- News is found with Google News searches in Urdu and in English for each district (Urdu and English names, towns and valleys), so it covers many outlets.

Needs internet to load new stories. Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `FataNews-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+).
